# 🚌 Bus Ticket Booking App

A Flutter-based mobile application for booking bus tickets with user authentication and a simple booking interface.

## ✨ Features

* User Sign Up & Login
* Forgot Password
* Bus Ticket Booking
* Home Page
* Splash Screen
* Custom Theme

## 🛠️ Tech Stack

* Flutter
* Dart
* Material UI

## 🚀 How to Run

```bash
git clone https://github.com/chinmayee302006/bus-ticket-booking-app.git
cd bus-ticket-booking-app
flutter pub get
flutter run
```
